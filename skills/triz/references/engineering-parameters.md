# TRIZ 39 Engineering Parameters

These 39 parameters cover most types of improvements and trade-offs in engineering and design problems. When helping the user map their contradiction, look for the closest match — it's about capturing the *essence* of what's improving or worsening, not finding a perfect fit.

| # | Parameter | Description |
|---|-----------|-------------|
| 1 | Weight of moving object | Mass of an object that can move (vehicle, tool, robot arm, etc.) |
| 2 | Weight of stationary object | Mass of an object that doesn't move in use (building, fixture, base) |
| 3 | Length of moving object | Any linear dimension (length, height, width) of a moving object |
| 4 | Length of stationary object | Any linear dimension of a stationary object |
| 5 | Area of moving object | Surface area of a moving object (footprint, cross-section) |
| 6 | Area of stationary object | Surface area of a stationary object |
| 7 | Volume of moving object | Space occupied by a moving object |
| 8 | Volume of stationary object | Space occupied by a stationary object |
| 9 | Speed | Velocity of a process or object; rate of completing a task |
| 10 | Force | Interaction between systems; force applied to an object |
| 11 | Stress or pressure | Force per unit area inside an object or fluid |
| 12 | Shape | External geometry or contour of a system |
| 13 | Stability of composition | Wholeness/integrity of the system; resistance to disintegration |
| 14 | Strength | Ability of an object to resist breaking under load |
| 15 | Duration of action (moving) | Time an object or process can perform its function while moving |
| 16 | Duration of action (stationary) | Time an object or process can perform its function while stationary |
| 17 | Temperature | Thermal condition of a system |
| 18 | Illumination intensity | Brightness, light flux, or clarity of lighting |
| 19 | Energy use by moving object | Amount of energy consumed by a moving object |
| 20 | Energy use by stationary object | Amount of energy consumed by a stationary object |
| 21 | Power | Rate at which work is performed; energy per unit time |
| 22 | Loss of energy | Energy wasted through heat, friction, or inefficiency |
| 23 | Loss of substance | Material lost through leakage, wear, evaporation, etc. |
| 24 | Loss of information | Degradation or loss of data, signal, or knowledge |
| 25 | Loss of time | Time wasted; delays in a process |
| 26 | Quantity of substance/matter | Amount of material, parts, or components in the system |
| 27 | Reliability | Ability of a system to perform its function consistently and without failure |
| 28 | Measurement accuracy | Closeness of a measured value to the true value |
| 29 | Manufacturing precision | Exactness of tolerances and reproducibility in production |
| 30 | Harmful effects on object | Negative side effects experienced by the object being acted on |
| 31 | Harmful side effects | Undesired effects generated by the system that affect the environment or other systems |
| 32 | Ease of manufacture | Simplicity and convenience of making or assembling the system |
| 33 | Ease of operation | Simplicity of using the system; user-friendliness |
| 34 | Ease of repair | Simplicity and speed of maintenance and repair |
| 35 | Adaptability / versatility | Ability of the system to respond to changing conditions or requirements |
| 36 | Device complexity | Number and variety of parts and their interactions |
| 37 | Difficulty of detecting | Difficulty in measuring or monitoring the system's state or parameters |
| 38 | Extent of automation | Level to which the system performs its function without human intervention |
| 39 | Productivity | Output per unit time; throughput of the system |

## Tips for mapping

- When the problem is about **software/digital systems**, map to logical analogues: "Weight" → complexity/file size; "Strength" → robustness/error tolerance; "Speed" → response time; "Loss of information" → data quality.
- When multiple parameters fit, pick the one that best captures *why* the trade-off exists, not just the surface symptom.
- It's valid to try 2–3 combinations and see which gives the most useful Inventive Principles.
